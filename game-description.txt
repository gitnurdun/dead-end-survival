
单机单人2d横板僵尸游戏：灵感来自多款经典僵尸游戏（手游僵尸村庄2）

玩法：
用键盘控制：方向键控制运动 空格来攻击（挥拳挥剑开枪等） x切换武器 r装子弹等

整个游戏从左走到尽头，路上有高台（类似超级玛丽），安全屋（可以躲避，有时候刷新血条子弹等物资），各种视觉元素，以及最后货架；


地图：
每个关卡设计不同风格：太阳系各个星球、各种地貌（森林、山地、公路等等）、各种天气、各种机关（保护或者伤害玩家的）、等等；能想到的都算起码30+地图；

僵尸：
包含各种；不同大小，不同外表，不同大小，不同伤害，不同技能，不同血条等等；每个关卡可以有自己的特色僵尸；可以参考植物大战僵尸各种元素；

小角色： 可以是跟随玩家的 小士兵、小护士、小狗、小机器人；也可以是跟随僵尸的小感染动物等；

武器：
包括冷兵器，如棒子，飞镖，大砍刀等等起码10+；热武器，各种手枪，机枪，喷火枪起码10+个；新概念武器，比如各种科幻武器，起码5+；

核心循环 —— 走到街道尽头的栅栏
 
```
起点 ──► 头段 ──► 随机中段 ×4~6 ──► 尾段 ──► 🚧 栅栏 ──► 货架商店 ──► 下一关
                                              ↑
                                     越过分界线 → 本关结束，停止刷僵尸
```

| 阶段 | 行为 |
|---|---|
| 一路推进 | 僵尸持续刷新，越往前走越密（按已走过的距离提升难度，不再按波次） |
| 越过栅栏 | **本关结束**，立刻停止刷僵尸，屏幕边缘泛白 + 音效提示"已抵达安全区" |
| 栅栏之后 | 一小段空街，尽头是**货架商店**。走过货架 → 结算 → 下一关 |

这些是大多数关卡，有些关卡可以有其他特色，比如守塔类型、开坦克或者直升机闯关等；


安全屋 —— 跳进去就安全，但房子会被砸塌
 
| 项 | 行为 |
|---|---|
| **进入** | 站在门口**向上跳** → 进入屋内。带进门音效  |
| **离开** | 屋内**再跳一下** → 出来。带出门音效 |
| **屋内** | **完全安全，僵尸永远打不到你**，想待多久待多久 |
| **玩家表现** | 进屋后**人物立刻消失** ，不再画门内剪影。人在里面的唯一提示是**窗户灯变得更亮、光晕更大** |
| **物资** | 同一个房子**只刷新 1~2 次**，刷完就不再出。跳进屋里自动拾取 |
| **窗户灯** | **绿色 = 还有物资**，**蓝色 = 已刷完**。屋外一眼可辨，**没有任何文字字幕** |
| **威胁** | **僵尸会砸房屋**，但**只砸 2~4 下就失去兴趣去游走**（4~9 秒），之后还会再回来砸。 被打会逐渐受损（裂纹 → 掉角冒烟 → 灯闪+倾斜），**最终倒塌消失**。倒塌时如果玩家还在里面 → 被弹到屋外地面上并扣 12 血 |



注意：这些这是初级想法，你需要还有发挥想象力，融合各种经典游戏元素，好好设计；
